**Author:** [[lauren-tan]] · **Raw:** `raw/2026-10-12-tan-x-short-posts.md` · Up: [[sources]]

## Summary and key claims
- **Cost caution** (2026-05-25): *"using multiple agents, especially frontier ones, use a lot of expensive tokens."* See [[budgets-and-cost]].
- **Organic architecture** (2026-07-18): agent-written code has made style-guide enforcement by code review obsolete, so *"codebases designed for agents need hard constraints."* Strong types and compiler diagnostics have *"far greater impact than AGENTS.md and tweaking your skills … the best rules are in your code."* See [[agent-experience]].
- **Gardener** (2026-08-20): *"every team needs a gardener"* who watches the PR stream for smells. *"every weed you pull becomes a rule, so it can't grow back."* See [[build-the-lever]].
- **pstack 10% smaller** (2026-10-11): *"no loss in behavior"*. Updates ship automatically in Grok Bot and Cursor. See [[pstack]].
