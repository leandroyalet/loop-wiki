# Observability

**Observability** means being able to see, after the fact, what a loop did and why. No ingested source treats it as a topic in its own right. This page collects the scattered evidence. Up: [[control]].

## Evidence so far
- **Transparency principle:** *"explicitly showing the agent's planning steps"* ([[src-anthropic-building-effective-agents]]).
- **Explained scheduling:** a self-paced `/loop` prints its chosen delay *and the reason* each iteration ([[src-claude-code-scheduled-tasks]]).
- **The state file as an audit trail:** it records what was tried, what passed and what is open ([[src-osmani-loop-engineering]]). See [[context-and-state]].
- **Watching the stream:** Huntley watches Ralph's output live to find patterns worth tuning ([[src-huntley-ralph]]).
- **Inbox, not silence:** in Codex, runs that find something go to a triage inbox and empty runs archive themselves ([[src-osmani-loop-engineering]]).
- **An audited decision log:** pstack's `/show-me-your-work` appends one row per decision (time, phase, decision, reason, evidence pointer, result) to `decisions.tsv`. At the end it checks the log against the transcript, and a reviewer from a **different model family** writes an **Attention** section. *"You're auditing decisions, not re-reading the whole night"* ([[src-tan-pstack-guide-overnight]]).
- **Evidence artifacts:** screenshots, videos, traces and heap snapshots posted by each stage. *"Artifacts … beat a plausible sounding explanation"* ([[src-tan-loops-you-can-trust]]).
- **Slack as a control room:** thread markers and status updates show the state of the whole line ([[src-tan-loops-you-can-trust]]).
- **Read thinking blocks** while you're in the loop to find failure modes worth encoding ([[src-tan-loops-you-can-trust]]).
- **Live streaming for AFK runs:** `--print` gives *"a blank screen"*. `--output-format stream-json` piped through `grep '^{' | tee | jq` streams assistant text live and keeps the final result for checking the sigil ([[src-pocock-afk-ralph-streaming]]).
- **Completion notification:** Pocock built a small CLI that pings him on WhatsApp when Ralph finishes, so he can *"fully engage with another task"* ([[src-pocock-ralph-tips]]).
- **The progress file and commits as a log:** each iteration appends decisions, blockers and files changed, and commits once per feature ([[src-pocock-ralph-tips]]).
- **Label AI output:** triage comments start *"This was generated by AI during triage"* ([[src-pocock-triage-skill]]).
- **Inspectable task lists:** `CronList` shows each scheduled task's ID, schedule and prompt ([[src-claude-code-scheduled-tasks]]).
